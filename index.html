OEE % acumulado e projeção do mês

Este gráfico mostra onde o OEE do mês deve fechar se os dias que faltam seguirem no nível atual. Esta página explica como a projeção é calculada, como ler a linha pontilhada e quais cuidados ter.

Resumo

O que mostra
O OEE % de cada dia, o OEE acumulado do mês e uma projeção até o último dia do mês.
Para que serve
Perceber cedo se o mês vai fechar abaixo ou acima do esperado, ainda com tempo de agir.
Como usar
Compare o fim da linha pontilhada com o acumulado. Use os filtros de estágio ou máquina para achar onde está o desvio.

Como ler o gráfico

  • Barras azuis: OEE % de cada dia. Mostram a oscilação diária, dia a dia.
  • Linha laranja contínua: Acumulado %. OEE do mês, do dia 1 até cada data, até o último dia com produção.
  • Linha laranja pontilhada: Projeção %. Supõe que os dias restantes repitam a média dos dias do mês.
  • Rótulos laranja: só dois pontos. O último dia com produção e o último dia do mês.

Cada ponto da linha é o OEE do mês até aquela data. O OEE de um dia isolado é a barra.

Como o cálculo funciona

O acumulado recalcula o OEE, não soma os dias

OEE é um percentual. Somar percentuais de dias diferentes daria valores absurdos, como 1.225%. A medida recalcula o OEE sobre todo o período, do dia 1 até a data. O resultado fica na mesma faixa dos OEEs diários.

A linha contínua termina no último dia com produção

O corte usa a última data de produção registrada até hoje. Datas futuras que já existem na base, como ordens programadas, não entram como realizado.

A projeção usa a média dos dias com produção

Para os dias que faltam, o sistema assume a média simples do OEE dos dias do mês que tiveram produção. Dias parados ou sem lançamento ficam fora dessa média.

Exemplo de cálculo
(80,2 + 57,1 + 87,9 + 71,4 + 79,7 + 50,9) ÷ 6 = 71,2%
Média dos seis dias com produção em 06/10/2026, vista nas barras do painel.

A projeção é uma média entre o realizado e a média dos dias

Cada dia já realizado entra com o acumulado real. Cada dia restante entra com a média dos dias. Quanto mais o mês avança, mais peso tem o realizado e menos a projeção se move.

Exemplo de cálculo
(70,0% × 6 dias + 71,2% × 25 dias) ÷ 31 dias = 71,0%
Acumulado de 70,0% no dia 6 e média dos dias de 71,2%. Resultado: projeção para o dia 31.

Tudo respeita os filtros da página

Estágio, máquina e Ano, Mês, Dia mudam as barras, o acumulado e a projeção. No dia 1 de cada mês o cálculo recomeça do zero.

O que é normal ver

  • Queda do acumulado logo no começo do mês.No dia 1 o acumulado é igual ao OEE do dia (80,2%). No dia 2 ele cai para perto de 68%, porque o dia 2 teve 57,1%. Com poucos dias no mês, cada dia pesa muito.
  • Barras que oscilam bastante.Em outubro os dias variaram de 50,9% a 87,9%. A linha de acumulado suaviza essa oscilação, e por isso é ela que indica a tendência do mês.
  • Projeção quase reta.A projeção mistura 6 dias reais com 25 dias estimados. Ela anda pouco de um dia para o outro. Em 06/10 vai de 70,0% a 71,0%.

Cuidados ao usar

  • A projeção não é meta nem previsão de produção.Ela mostra onde o mês fecha se os dias restantes repetirem a média dos dias. Plano de melhoria ou parada programada muda o resultado real.
  • Acumulado e média dos dias podem ser diferentes.Em 06/10 o acumulado é 70,0% e a média dos dias é 71,2%. No acumulado, os dias com mais produção pesam mais. A projeção parte do acumulado e caminha para a média dos dias.
  • Todos os dias futuros pesam igual.Fins de semana, feriados e paradas programadas distorcem a projeção de forma leve.
  • O dia de hoje entra como realizado.Se o apontamento do dia ainda estiver incompleto, o valor atual pode mudar ao longo do dia.
  • Atraso de apontamento muda a leitura.Antes de concluir algo, confirme com quem faz o apontamento se a produção dos últimos dias já foi lançada.

Perguntas frequentes

Por que não somamos o OEE dos dias?

Porque OEE é percentual. A soma de seis dias de cerca de 70% daria 420%. O acumulado recalcula o OEE sobre o período inteiro e fica na faixa dos valores diários.

Por que a projeção termina em 71,0% se o acumulado é 70,0%?

A projeção caminha do acumulado (70,0%) para a média simples dos dias (71,2%). Com 25 dias ainda por vir, ela chega perto da média, mas mantém o peso dos 6 dias já realizados.

A linha pontilhada muda de um dia para o outro?

Sim. A cada atualização dos dados, o acumulado e a média dos dias mudam, e a projeção é recalculada.

Posso ver só um estágio ou uma máquina?

Sim. Use os filtros Estágio e Máquina (Abridor, Calandra Algod., Calandra Bril., Rama, Secador e suas máquinas). Barras, acumulado e projeção se ajustam ao filtro.

O que acontece na virada do mês?

O acumulado recomeça no dia 1. Nos primeiros dias do mês, espere oscilações maiores.

Existe versão acumulada do ano?

Hoje o gráfico é mensal. Uma versão anual é possível e deve ser pedida ao time de BI.

Fórmulas DAX e configuração do visual
  • Tabela fato: 'OP_ITENS E900EOQ', coluna [DATA]. Calendário: dCalendarprod, com a coluna Date.
  • Visual combinado: eixo X Date, colunas [OEE %], linha OEE_acumulado (Acumulado %) e linha OEE_acumulado_futuro (Projeção %). Os rótulos laranja vêm da medida Rotulo_OEE_Projecao.
  • OEE_sem_contexto usa AVERAGEX, então é média simples dos OEEs diários. O TOTALMTD recalcula o [OEE %] no período, ponderado pela produção. Por isso os dois valores diferem.
  • Se o apontamento atrasar, troque TODAY() por TODAY() - 1 em Data_ultima_producao.
  • A variável possuiProducaoNoMes em OEE_acumulado_futuro não é usada no cálculo e pode ser removida.
Data_ultima_producao
Data_ultima_producao =
CALCULATE(                                  // Altera o contexto de avaliação do cálculo
    MAX('OP_ITENS E900EOQ'[DATA]),          // Busca a maior data (mais recente) cadastrada na tabela de produção
    ALL(dCalendarprod),                     // Remove filtros da tabela de calendário para analisar todo o histórico
    'OP_ITENS E900EOQ'[DATA] <= TODAY()     // Filtra para considerar apenas registros até o dia de hoje (evita dados futuros incorretos)
)
OEE_acumulado
OEE_acumulado =
VAR dt = [Data_ultima_producao]             // Guarda a data da última produção em uma variável chamada 'dt'
RETURN                                      // Inicia o retorno do resultado
IF(                                         // Inicia uma verificação condicional
    MAX(dCalendarprod[Date]) <= dt,         // Verifica se a data exibida no gráfico é menor ou igual à última data com produção
    TOTALMTD(                               // Calcula o acumulado do início do mês até a data atual (Month-To-Date)
        [OEE %],                            // A medida do OEE percentual diário que será acumulada
        dCalendarprod[Date]                 // A coluna de datas do calendário usada para acumular o mês
    )                                       // Fecha a função TOTALMTD
)                                           // Fecha a função IF (se a data for futura, retorna em branco)
OEE_acumulado_futuro
OEE_acumulado_futuro =
VAR dt = [Data_ultima_producao]                                     // Guarda a data da última produção na variável 'dt'
VAR dtAtual = MAX(dCalendarprod[Date])                              // Captura a data específica que o gráfico está desenhando no momento

// Verifica se a máquina realmente produziu dentro do mês visível
VAR possuiProducaoNoMes = NOT ISBLANK([OEE %]) || NOT ISBLANK([OEE_acumulado]) // Testa se há dados no mês (não utilizada diretamente no RETURN)

RETURN                                                              // Inicia o bloco de cálculo final
IF(                                                                 // Verifica se pode calcular a projeção
    NOT ISBLANK(dt) && dtAtual >= dt,                               // Calcula APENAS se existir data de produção E se a data for igual ou futura à última produção
    VAR diasFuturos = DATEDIFF(dt, dtAtual, DAY)                    // Conta quantos dias se passaram entre a última produção e a data futura
    VAR diasReais = DAY(dt)                                         // Pega o número do dia da última produção (ex: dia 5 = 5 dias reais passados)
    VAR oeeReal = CALCULATE([OEE_acumulado], dCalendarprod[Date] = dt) // Resgata o valor exato do OEE acumulado real até o último dia produzido

    RETURN                                                          // Inicia o retorno da fórmula matemática
    DIVIDE(                                                         // Faz uma divisão segura para evitar erros por zero
        oeeReal * diasReais + [OEE_sem_contexto] * diasFuturos,     // Numerador: (OEE real × dias reais) + (média diária × dias futuros)
        diasReais + diasFuturos                                     // Denominador: soma total de dias (reais + futuros) para a média ponderada
    )                                                               // Fecha a função DIVIDE
)                                                                   // Fecha a função IF
OEE_sem_contexto
OEE_sem_contexto =
VAR dt = [Data_ultima_producao]             // Armazena a data da última produção na variável 'dt'
VAR iniMes = DATE(YEAR(dt), MONTH(dt), 1)   // Identifica qual foi o dia 01 do mês daquela última produção

RETURN                                      // Inicia o retorno do cálculo
CALCULATE(                                  // Modifica os filtros para calcular a média
    AVERAGEX(                               // Percorre a tabela dia por dia para tirar a média
        VALUES(dCalendarprod[Date]),        // Pega a lista de dias únicos do calendário
        [OEE %]                             // Calcula a média em cima do OEE diário
    ),                                      // Fecha a função AVERAGEX
    FILTER(                                 // Aplica um filtro personalizado
        ALL(dCalendarprod[Date]),           // Limpa filtros de data para olhar todo o intervalo do mês
        dCalendarprod[Date] >= iniMes       // Considera dias a partir do dia 1º do mês
            && dCalendarprod[Date] <= dt    // Até o dia da última produção registrada
            && NOT ISBLANK([OEE %])         // Ignora dias em que não houve produção (dias em branco/parados)
    )                                       // Fecha a função FILTER
)                                           // Fecha a função CALCULATE
Rotulo_OEE_Projecao
Rotulo_OEE_Projecao =
VAR dt = TRUNC([Data_ultima_producao])      // Pega a data da última produção e remove horas/minutos para garantir data pura
VAR dtAtual = MAX(dCalendarprod[Date])      // Identifica o dia atual do eixo X no gráfico

VAR dtFimMes = EOMONTH(dtAtual, 0)          // Descobre qual é o último dia do mês atual (ex: dia 30 ou 31)

RETURN                                      // Inicia o retorno
IF(                                         // Inicia a condição de exibição
    dtAtual = dt || dtAtual = dtFimMes,     // Testa se o dia no gráfico é O DIA DA ÚLTIMA PRODUÇÃO ou O ÚLTIMO DIA DO MÊS
    [OEE_acumulado_futuro]                  // Se for um desses dois dias, mostra o número da projeção
)                                           // Fecha a função IF (retorna vazio nos outros dias)
